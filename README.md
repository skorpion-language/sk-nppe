## Skorpion Extension
Skorpion syntax highlighting extension for Notepad++

Adding:
- Syntax highlighting in Skorpion's files (`.sk`, `.spc`)

## Version
Corresponds to Skorpion version `2026.10.b01`.

## Install

1. Save files `sk-nppe.xml` and `spc-nppe.xml`
2. Open Notepad++
3. Click `Language` -> `User Defined Language` -> `Define your language...`
4. In opened window click `Import...`
5. Select downloaded files and click `Open`
6. Done!

> If after p. 5 you see `Fail to import.` create [issue here](https://).
